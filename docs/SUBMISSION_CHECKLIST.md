# Submission checklist — Qloo LLM Hackathon

Confirm the exact requirements on the official Devpost page before submitting — this is the usual shape.

## Repo
- [ ] Public GitHub repo (this one), MIT licensed
- [ ] README: what it does, how to run, architecture diagram, which Qloo endpoints are used
- [ ] No secrets committed (`.env` is gitignored; `.env.example` documents keys)
- [ ] Runs cleanly from a fresh clone (`pip install -r requirements.txt` → `python -m src.main "..."`)

## Demo video (2–3 min)
- [ ] Show the problem in one line
- [ ] Live run: a taste prompt → the agent calling Qloo → a grounded plan
- [ ] Explicitly point out where Qloo's taste graph does the work (judges look for this)
- [ ] Upload to YouTube (unlisted is fine) and link it on Devpost

## Devpost entry
- [ ] Project title + tagline
- [ ] "What it does" / "How we built it" / "What's next"
- [ ] Tech used (Python, Qloo API, Gemini)
- [ ] Repo link + video link
- [ ] Any required mini-challenge / feedback form filled (these often have their own small prizes)

## Admin (India)
- [ ] If asked, a **W-8BEN** for US-based prize payout
- [ ] Keep a record — prize income is taxable in India
